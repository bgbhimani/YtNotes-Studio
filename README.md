# YtNotes Studio

YtNotes Studio is a powerful tool designed to help you create, manage, and share notes for YouTube videos. Whether you're a student, educator, or content creator, YtNotes Studio provides an intuitive interface to organize your thoughts and insights while watching YouTube videos.

## Video Link
[Youtube](https://youtu.be/2RaJzQ7KW0w?si=3HstxYtlOXaryQmx)


## Features

- **Create and Edit Notes**: Easily create and edit notes while watching videos.
- **Organize by Video**: Keep your notes organized by associating them with specific YouTube videos.
